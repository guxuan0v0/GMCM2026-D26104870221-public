## 关于本仓库

本仓库是我们参加 **2026 年"华为杯"中国研究生数学建模竞赛**（D 题）的公开代码与结果仓库。

也就是说：本仓库目前仅作占位与说明之用，竞赛成绩公布后，我们会把四个问题的完整求解代码、关键结果表格、绘图脚本以及论文复现说明一并推送至此仓库。

## 选题简介

题目以 **2026 年 7 月广西横州市镇龙乡洪涝灾害** 为背景（受台风"美莎克"持续强降雨影响，当地曾出现断路、断电、断网，全乡约 8000 人受困）。场景包含 1 个临时调度中心、15 个服务区、80 个不可拆货箱、3 种运输无人机机型（共 8 架实体运输无人机）、共享电池组、中继无人机、可更换能源组件以及 30 米 DEM 地形数据。

在道路受阻、能源受限、通信中断的条件下，需要协同解决**物资运输组织**、**通信中继保障**与**有限救援资源调配**三类问题：

| 问题 | 内容 |
| --- | --- |
| 问题一 | 单点往返运输能力与货箱组批方案：计算三种机型在不同服务区的最大安全载荷，在载质量、装载体积与返航安全能量余量约束下确定组批方案，并权衡架次数、总能耗与作业时间 |
| 问题二 | 异构无人机多点多架次运输调度：联合确定货箱组批、服务区访问顺序、机型与执行无人机、共享电池分配及各架次开始时刻，兼顾配送及时性、任务完成时间、能耗与架次数 |
| 问题三 | 通信约束下的运输与中继联合调度：保证运输无人机全阶段连续通信，联合确定中继无人机悬停位置、飞行海拔、服务时段与能源组件分配 |
| 问题四 | 救援任务分区与资源配置优化：将 15 个服务区划分为 2 个和 3 个任务组，核算各组独立执行所需资源，比较资源冗余、工作量均衡与配置缺口 |
